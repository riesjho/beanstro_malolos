# Beanstro Coffee

Single-page menu site for Beanstro Coffee in Binondo — bright orange branding, sticky category nav, and editable menu prices.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3456](http://localhost:3456).

## Edit the menu

Update prices and items in [`src/data/menu.ts`](src/data/menu.ts). Cafe details live in [`src/data/cafe.ts`](src/data/cafe.ts).
